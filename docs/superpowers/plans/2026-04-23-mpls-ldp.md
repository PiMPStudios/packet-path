# MPLS + LDP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add MPLS label switching to Packet Path — labels are auto-assigned when LDP is enabled on a router, packets display a glowing badge with the top-of-stack label, and a dedicated MPLS tab shows the LFIB per device.

**Architecture:** Option A (simplified) — IP routing (OSPF) determines the forwarding path; LDP bindings are synthetic (no hello/keepalive FSM). When `ldpEnabled=true` on a router, `UpdateLdp()` computes a Label Forwarding Information Base (LFIB) from the current routing table and OSPF neighbors. `SimulateForward` decorates each hop with a `LabelOp` (PUSH/SWAP/POP) using the LFIB, the packet animation displays the current label as an orange badge above the dot, and the Trace Modal shows the label op per hop.

**Tech Stack:** C++17, raylib 5.x, nlohmann/json, make (wildcard build — any `src/*.cpp` is auto-included, no Makefile changes needed)

### Task 2: LDP Engine

Implement `UpdateLdp()` — the function that reads each router's routing table and builds its LFIB. Called once per frame after `UpdateOspf()`.

**Algorithm:**
- Phase 1: For each `ospfEnabled && ldpEnabled` router, assign a local label per prefix. CONNECTED prefixes get `MPLS_IMPLICIT_NULL` (triggering PHP at the penultimate hop). Non-CONNECTED prefixes get `node.id * 100 + idx` where `idx` increments per unique non-connected prefix.

```cpp
#include "LdpEngine.h"
#include <unordered_map>
#include <string>

// Returns the node ID of the directly-connected neighbor that owns nextHopIp.
static int FindNbrNodeId(int nodeId, const std::string& nextHopIp,
                          const std::vector<DeviceNode>& nodes,
                          const std::vector<Cable>& cables)
{
    for (const auto& c : cables) {
        int candidateId = -1;
        if      (c.fromId == nodeId) candidateId = c.toId;
        else if (c.toId   == nodeId) candidateId = c.fromId;
        if (candidateId == -1) continue;

        const DeviceNode* nb = FindNode(nodes, candidateId);
        if (!nb) continue;
        for (int i = 0; i < PORTS_PER_NODE; ++i) {
            const auto& ip = nb->portIp[i];
            if (ip.empty()) continue;
            auto slash = ip.find('/');
            std::string plain = (slash != std::string::npos)
                                ? ip.substr(0, slash) : ip;
            if (plain == nextHopIp) return candidateId;
        }
    }
    return -1;
}

void UpdateLdp(std::vector<DeviceNode>& nodes,
               const std::vector<Cable>& cables)
{
    // Clear all existing LFIB tables
    for (auto& n : nodes) n.lfib.clear();

    // Phase 1: build routerId → {networkAddr → localLabel}
    // CONNECTED prefixes advertise MPLS_IMPLICIT_NULL (signals PHP to prev hop).
    // Non-CONNECTED prefixes get node.id*100 + per-router index.
    std::unordered_map<std::string,
        std::unordered_map<std::string, uint32_t>> bindingMap;

    for (const auto& n : nodes) {
        if (n.type != ROUTER || !n.ospfEnabled || !n.ldpEnabled) continue;
        if (n.routerId.empty()) continue;

        uint32_t localBase = (uint32_t)n.id * 100u;
        uint32_t idx       = 0;
        auto table = GetRoutingTable(n);

        for (const auto& route : table) {
            std::string prefix = NetworkAddress(route.dest);
            if (prefix.empty()) continue;
            if (bindingMap[n.routerId].count(prefix)) continue;  // deduplicate

            if (route.src == ROUTE_CONNECTED) {
                bindingMap[n.routerId][prefix] = MPLS_IMPLICIT_NULL;
            } else {
                bindingMap[n.routerId][prefix] = localBase + idx++;
            }
        }
    }

    // Phase 2: for each ldpEnabled router, build LFIB
    for (auto& n : nodes) {
        if (n.type != ROUTER || !n.ospfEnabled || !n.ldpEnabled) continue;
        if (n.routerId.empty()) continue;

        auto myBindings = bindingMap.find(n.routerId);
        if (myBindings == bindingMap.end()) continue;

        auto table = GetRoutingTable(n);
        for (const auto& route : table) {
            if (route.src == ROUTE_CONNECTED) continue;

            std::string prefix = NetworkAddress(route.dest);
            if (prefix.empty()) continue;

            auto myLbl = myBindings->second.find(prefix);
            if (myLbl == myBindings->second.end()) continue;

            // Resolve next-hop router
            int nbrId = FindNbrNodeId(n.id, route.nextHop, nodes, cables);
            if (nbrId == -1) continue;
            const DeviceNode* nbr = FindNode(nodes, nbrId);
            if (!nbr || !nbr->ldpEnabled || nbr->routerId.empty()) continue;

            auto nbrBindings = bindingMap.find(nbr->routerId);
            if (nbrBindings == bindingMap.end()) continue;
            auto nbrLbl = nbrBindings->second.find(prefix);
            if (nbrLbl == nbrBindings->second.end()) continue;

            LdpBinding binding;
            binding.localLabel = myLbl->second;
            binding.outLabel   = nbrLbl->second;
            n.lfib[prefix]     = binding;
        }
    }
}
```

### Task 3: MPLS-Aware Forwarding

Extend `SimulateForward` to decorate each `HopDecision` with a `LabelOp` and label values using the router's LFIB. Then extend `DrawTraceModal` to display the label op per hop.

**Label op rules (per hop):**
- `currentLabel == 0` and router has LFIB entry → `LABEL_PUSH`, `outLabel = lfib.outLabel`
- `currentLabel != 0` and `lfib.outLabel == MPLS_IMPLICIT_NULL` → `LABEL_POP`, `outLabel = 0` (PHP)
- `currentLabel != 0` and `lfib.outLabel != MPLS_IMPLICIT_NULL` → `LABEL_SWAP`, `outLabel = lfib.outLabel`
- No LFIB entry, or CONNECTED delivery → `LABEL_NONE`
