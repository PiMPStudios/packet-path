# ACL + Basic NAT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add per-device ACLs (permit/deny by prefix + optional destination port) and basic source NAT (PAT/overload) to Packet Path, with config panel tabs, packet simulation enforcement, trace modal annotations, and two new teaching levels.

**Architecture:** A new `AclEngine` provides stateless prefix-matching and rule evaluation. `SimulateForward` gains a `srcIp` parameter and a `lastIngressPort` tracker so ACL rules fire correctly on the right interface in both directions. NAT is a per-hop annotation: when a packet leaves the NAT outside port with a matching source prefix, `HopDecision.natResult` is set; the trace modal displays this. Two new config panel tabs (ACL, NAT) follow the VXLAN tab pattern exactly. Levels 15–16 exercise each feature independently.

**Tech Stack:** C++17, raylib 5.x, nlohmann/json. Build: `make` (Makefile uses `$(wildcard src/*.cpp)` — new `.cpp` files are picked up automatically).

- [ ] **Step 2: Create `src/AclEngine.cpp`**

```cpp
#include "AclEngine.h"
#include <cstdio>

static uint32_t IpToU32(const std::string& ip) {
    unsigned a = 0, b = 0, c = 0, d = 0;
    std::sscanf(ip.c_str(), "%u.%u.%u.%u", &a, &b, &c, &d);
    return (a << 24) | (b << 16) | (c << 8) | d;
}

bool AclMatchPrefix(const std::string& ip, const std::string& cidr) {
    if (cidr == "any" || cidr.empty()) return true;
    if (ip.empty()) return true;   // empty srcIp = wildcard (underlay hops)
    auto slash = cidr.find('/');
    if (slash == std::string::npos) {
        // host match
        return ip == cidr;
    }
    int bits = std::stoi(cidr.substr(slash + 1));
    uint32_t mask = (bits == 0) ? 0u : (~0u << (32 - bits));
    uint32_t network = IpToU32(cidr.substr(0, slash)) & mask;
    return (IpToU32(ip) & mask) == network;
}

const AclRule* MatchAcl(const std::vector<AclRule>& rules,
                          const std::string& srcIp,
                          const std::string& dstIp,
                          int dstPort) {
    for (const auto& r : rules) {
        if (!AclMatchPrefix(srcIp, r.srcCidr))              continue;
        if (!AclMatchPrefix(dstIp, r.dstCidr))              continue;
        if (r.dstPort != 0 && r.dstPort != dstPort)         continue;
        return &r;
    }
    return nullptr;   // no match → implicit deny
}
```
